# Sacred Ones website

The public website for Sacred Ones (sacredones.org), Fort Peck Reservation.

- `index.html` — home, projects and culture views (Material 3, earth tones)
- `lessons/` — seven lessons on Oceti Sakowin history and culture
- `store/` — merchandise request page (emails sacredones22@gmail.com)
- `assets/commons/credits.json` — credits and licenses for historic and Creative Commons images
- `m3.css`, `m3.js` — shared design system

Static files only; no build step. The game loads from
https://www.sacredones.org/SacredAdventures/SacredOnes.html.

Contact: sacredones22@gmail.com
